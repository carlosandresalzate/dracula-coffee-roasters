# 🦇 Dracula Coffee Roasters

[Dracula Coffee Roasters](https://carlosandresalzate.github.io/dracula-coffee-roasters/)

## Pre Entrega Del Proyecto Final.

Sitio web E-commerce desarrollado como proyecto para el curso de **FrontEnd-JS de Talento Tech**.

La propuesta consiste en el desarrollo de la interfaz de una tienda de café de especialidad ficticia llamada **Dracula Coffee Roasters**, utilizando HTML y CSS para construir la estructura y presentación visual del sitio.

Esta entrega corresponde a la etapa inicial del proyecto, en el que se trabaja principalmente sobre el **maquetado**, la estructura del proyecto y los estilos.

## ☕ Descripción del proyecto

**Dracula Coffee Roasters** es una propuesta de e-commerce ficticio orientado a la comercialización de **cafés de especialidad y microlotes**.

El sitio presenta una identidad visual inspirada en una estética oscura, elegante y experimental, combinando elementos relacionados con el café de especialidad, la botánica y la temática nocturna.

## 🦇 Inspiración y diseño

La identidad visual del proyecto está inspirada en el **theme Dracula**, tomando como referencia su estética oscura y el contraste característico de este tipo de interfaces.

La intención no fue realizar una copia del theme, sino utilizarlo como punto de partida para crear una identidad propia.

Para definir la propuesta visual y generar material gráfico para el proyecto se utilizó **Stitch de Google**, solicitándole generar propuestas de diseño e imágenes que pudieran utilizarse como referencia y como recursos dentro del sitio.

A partir de estas propuestas se realizó posteriormente el **maquetado HTML y CSS**, adaptando el diseño a la estructura del proyecto.

## ✅ Requisitos

Es un proyecto simple de HTML y CSS: no necesita Node.js, npm ni ninguna dependencia. Solo se necesitan:

- [Git](https://git-scm.com/)
- [Visual Studio Code](https://code.visualstudio.com/) o cualquier editor de texto
- Conexión a internet (las fuentes e íconos se cargan desde Google Fonts; las fuentes locales funcionan como respaldo)

### Extensiones de VS Code utilizadas

- [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer): para levantar un servidor local con recarga automática.
- [Prettier - Code formatter](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode) - Code formatter: para mantener el código formateado.
- [EditorConfig for VS Code](https://marketplace.visualstudio.com/items?itemName=EditorConfig.EditorConfig): para mantener un estilo de edición consistente.

## 🛠️ Tecnologías utilizadas

### Google Fonts

Se utilizan:

- **EB Garamond**
- **Plus Jakarta Sans**

Ambas tipografías también cuentan con archivos locales dentro del proyecto para permitir su utilización mediante `@font-face`.

### Material Symbols

Los iconos de la interfaz se implementan mediante **Material Symbols de Google**.

Se utilizan iconos para representar acciones y elementos como:

- búsqueda
- usuario

- etc.

La carga de estos iconos se realiza mediante Google Fonts.

## 💻 Instalación y ejecución local

Este proyecto no requiere Node.js, npm ni ninguna dependencia adicional para visualizar esta versión.

Al tratarse de una implementación basada en **HTML + CSS**, puede ejecutarse directamente desde un navegador.

### 🚀 Cómo clonar y ejecutar el proyecto

1. **Clonar el repositorio**
   Desde una terminal:

   ```bash
   git clone https://github.com/carlosandresalzate/dracula-coffee-roasters.git
   ```

2. **Entrar a la carpeta del proyecto**

   ```bash
   cd dracula-coffee-roasters
   ```

3. **Abrirlo en VS Code**

   ```bash
   code .
   ```

   También se recomienda utilizar **Visual Studio Code** junto con una extensión como **Live Server**, para disponer de un servidor local y recarga automática durante el desarrollo.

### 3. Ejecutar con Live Server

Desde Visual Studio Code:

1. Abrir la carpeta del proyecto.
2. Abrir `index.html`.
3. Seleccionar **Open with Live Server**.
4. El navegador abrirá el sitio en una dirección local.

Por ejemplo:

```text
http://127.0.0.1:5500/
```

o

```text
localhost:5500
```

> 💡 También se puede abrir `index.html` directamente en el navegador, pero se recomienda Live Server para que las rutas relativas y la recarga automática funcionen correctamente.
